# 🚀 Tech / Developer Conference Web Page

A responsive and modern landing page built for a developer conference ("DevConf 2026"). This web page showcases featured speakers, ticket pricing plans, event schedules, and essential conference details with a clean and user-friendly interface.

🌐 **Live Demo:** [View Live Website](https://nayemmizee-profile.github.io/assignment-01/)

---

## ✨ Features

- **Hero Section:** Clear headline and event summary inviting developers, founders, and engineers.
- **Speakers Section:** Displays key speakers with their photos, roles, and expertise.
- **Pricing & Registration:** Transparent pricing tiers (Standard, Pro, and Team) with detailed perk breakdown.
- **Interactive Schedule:** Day-by-day event breakdown (Keynotes, Workshops, Panels, and Networking).
- **Navigation & Footer:** Easy layout navigation with links to social media handles and legal notices.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic HTML structure.
- **CSS3:** Custom styling and responsive design.
